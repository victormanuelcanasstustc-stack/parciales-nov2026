**Evaluación:** Parcial Técnico 2

## Contenido

El desarrollo de esta evaluación está organizado en cinco preguntas:

1. Revisión de código y clasificación de hallazgos.
2. Análisis comparativo de herramientas de revisión de código.
3. Clasificación de pruebas y estabilidad de la suite.
4. Análisis y corrección de un workflow de integración continua.
5. Evaluación de resultados, métricas y confiabilidad.

El documento principal contiene las respuestas desarrolladas y la conclusión general.

## Estructura del directorio

- `respuestas.md`: desarrollo de las cinco preguntas y conclusión.
- `respuestas_respaldo.md`: copia de respaldo del documento.
- `scripts/`: scripts auxiliares de la evaluación.
- `archivos_prueba/`: archivos utilizados para las pruebas.
- `evidencias/`: capturas y resultados de las ejecuciones.

## Reproducibilidad y evidencias

Los comandos, resultados y cálculos incluidos en el documento deben corresponder a ejecuciones verificables. Las evidencias se incorporarán en el directorio correspondiente.

## Entrega

El documento final se entregará en formato PDF, conservando la numeración y el orden de las preguntas. Los archivos complementarios necesarios se mantendrán dentro de este directorio.
